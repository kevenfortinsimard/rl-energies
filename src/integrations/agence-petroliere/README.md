# Intégration `agence-petroliere`

Agence Pétrolière (division transport d'RL) : outil de transport et piges, intégrés au module dispatch.

Rôle : traduire les données de ce système en types internes. Les modules métier appellent ce dossier, jamais le système externe directement.
Variables d'environnement : voir `.env.example`.

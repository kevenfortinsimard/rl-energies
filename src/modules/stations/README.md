# Module `stations`

Réseau de stations (bannières RL Énergies, Pétroles Belzile, Rezzo) et leurs équipements : pompes, réservoirs, bornes de recharge.

Entités et dépendances : voir [docs/modules.md](../../../docs/modules.md).

- `index.ts` : API publique (seul point d'entrée pour les autres modules)
- `types.ts` : types du domaine
- `service.ts` : logique métier
